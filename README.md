# 《大工饮食指南》作品说明

**作品定位**：面向大连理工大学开发区校区新生的校园餐饮决策助手，用一个网页解决"每天吃什么"。

## 一、对应的真实问题

新生入校后，每天都要高频面对三件现实困扰：一是**选择困难**——第六食堂一、二楼共 15 个窗口、数百道菜品，从大伙快餐到麻辣烫、轻食、韩餐、汉堡应有尽有，每顿"吃什么"都要纠结半天；二是**预算与营养难两全**——想省钱、想增肌、想减脂、想清淡，这些诉求常常互相冲突，学生缺少量化的搭配依据，只能凭感觉点单；三是**信息分散**——各窗口的招牌菜、价位、营业时段，以及周边隐藏好店，散落在不同渠道，缺少一站式的整理与引导。

## 二、创意思路

作品以"帮用户做决策"为核心，把零散餐饮信息转化为四类可交互的引导：

1. **食堂决策导航**：属性（排队热门 / 人少清净 / 实惠 / 营养自助）与口味类型（麻辣 / 清淡 / 面食 / 饭类 / 炸物 / 轻食）双维筛选；点任一窗口弹出详情，展示完整菜品、价格与 AI 估算营养，并支持 1–5 星评分与文字评论、数据云端同步；红色"今天吃啥"一键随机替选择困难者拍板。
2. **营养预算餐单生成器**：设定预算（20–100 元）、目标（增重 / 均衡 / 减脂）与忌口（少辣 / 清真 / 低油 / 素食），一键生成周一至周日三餐搭配，每餐标注热量与价格，可"换一批"重组。
3. **周边隐藏美食地图**：按"步行 5 分钟 / 性价比 / 夜宵党"场景筛选校外选择；点店卡弹出详情，内嵌高德地图红点定位、显示位置与距离，一键跳转高德导航。
4. **营养智库**：从 197 道真实菜品中挑 1–3 道，即时合计热量、蛋白质、碳水、脂肪并对照目标给出诊断徽章与可执行建议，另设高蛋白 / 低脂 / 高性价比三张 TOP8 排行榜。

## 三、操作流程

1. 打开页面，头图即展示定位与关键数据（15 档口、1 清真、197 菜谱、8 周边店）；
2. "食堂导航"：属性 + 口味双维筛选，点"今天吃啥"随机推荐，点卡片看菜品、营养与评分；
3. "餐单生成"：设预算、目标与忌口，点"生成一周餐单"或"换一批"；
4. "周边美食"：场景筛选，点店卡看地图定位并跳转高德导航；
5. "营养智库"：挑菜后看指标卡、进度条、诊断与建议，切换排行榜了解"最高蛋白 / 最低脂 / 最划算"之选。

## 四、应用效果

- **决策提效**：从"纠结半小时"到"一键决定"，把高频选择交给工具；
- **预算可控**：餐单在设定预算内搭配，价格真实可查，帮学生规划月开销；
- **营养帮助**：每道菜的热量与三大营养素一屏呈现，对照目标自动诊断并落到具体菜品建议，让健康诉求有据可循；
- **口碑可信**：窗口评分与评论存云端数据库、跨设备同步，帮新生避开"踩雷"；
- **数据可信**：15 个窗口、197 道菜品、8 家周边店均来自团队实测与公开资料，来源清晰标注。

**结语**：从"吃什么"的小切口出发，作品把选择困难、预算与营养这些日常烦恼，变成一页上手的贴心工具，愿每位开发区校区的新生都能少点纠结、吃得更踏实，更快融入大工的烟火日常。

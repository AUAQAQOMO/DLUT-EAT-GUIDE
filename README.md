# 《大工吃喝导航》作品说明

**作品定位**：面向大连理工大学开发区校区新生的校园餐饮决策助手，用一个网页解决"每天吃什么"。

## 一、对应的真实问题

新生入校后，每天都要高频面对三件现实困扰：一是**选择困难**——开发区校区第六食堂一、二楼共 15 个窗口，品类从大伙快餐、盖浇饭、瓦香鸡到麻辣烫、轻食、韩餐、汉堡应有尽有，每顿"吃什么"都要纠结半天；二是**预算与营养难两全**——想省钱、想增肌、想减脂、想吃得清淡，这些诉求常常互相冲突，学生缺少量化的搭配依据，只能凭感觉点单；三是**信息分散**——各窗口的招牌菜、人均价位、营业时段，以及周边隐藏的好店，散落在不同渠道，缺少一站式的整理与引导。这些看似琐碎的日常，恰恰是新生适应校园生活时最先遇到的摩擦点。

## 二、创意思路

作品以"帮用户做决策"为核心，把零散餐饮信息转化为四类可交互的引导：

1. **食堂决策导航**：用"排队热门 / 人少清净 / 实惠 / 营养自助"四个属性标签与"麻辣 / 清淡 / 面食 / 饭类 / 炸物 / 轻食"口味类型下拉框做双维筛选，卡片展示窗口名、楼层、招牌简介、人均与营业时段；红色"今天吃啥"按钮从当前结果中随机抽取一道并附推荐理由，替选择困难者直接拍板。
2. **营养预算餐单生成器**：设定每日预算（20–100 元）、饮食目标（增重 / 均衡 / 减脂）与忌口（少辣 / 清真 / 低油 / 素食），一键生成周一至周日三餐搭配，每餐标注估算热量与价格，支持"换一批"重新组合。
3. **周边隐藏美食地图**：按"步行 5 分钟 / 性价比 / 夜宵党"场景筛选校外选择，店卡含类型、一句话介绍、人均与距离。
4. **营养智库**：从 35 道真实菜品中挑 1–3 道，即时合计热量、蛋白质、碳水、脂肪并对照目标给出"均衡 / 热量偏高 / 蛋白质不足"等诊断徽章与可执行建议，另设高蛋白 / 低脂 / 高性价比三张 TOP8 排行榜。

## 三、操作流程

1. 打开页面，顶部头图即展示定位与关键数据（15 档口、1 清真、35 菜谱、8 周边店）；
2. "食堂导航"：先点属性筛选、再选口味类型缩小范围，点红色"今天吃啥"随机推荐；
3. "餐单生成"：设预算、选目标与忌口，点"生成一周餐单"，不满意点"换一批"；
4. "周边美食"：按场景筛选，查看店卡、距离与来源标注；
5. "营养智库"：挑菜后查看指标卡、进度条、诊断徽章与建议，切换排行榜了解"最高蛋白 / 最低脂 / 最划算"之选。

## 四、应用效果

- **决策提效**：从"纠结半小时"到"一键决定"，把高频选择交给工具；
- **预算可控**：餐单在设定预算内搭配，价格真实可查，帮助学生规划月开销；
- **营养帮助**：营养智库把每道菜的热量与蛋白质、碳水、脂肪一屏呈现，对照增肌 / 减脂 / 清淡等目标自动诊断并给出落到具体菜品的改进建议（如"蛋白偏低，再加一份牛肉汤"），让健康诉求有据可循；
- **数据可信**：15 个窗口、35 道菜品、8 家周边店均来自团队实测与公开资料，来源清晰标注，可离线使用。

**结语**：从"吃什么"的小切口出发，作品把选择困难、预算与营养这些日常烦恼，变成一页上手的贴心工具，愿每位开发区校区的新生都能少点纠结、吃得更踏实，更快融入大工的烟火日常。
